# 命理交叉验证系统（MingLi Cross-Validation System）

将 **四柱八字、紫微斗数、周易、铁板神数** 四套传统命理体系，统一映射到 7 个人生维度，
进行多源交叉验证，输出分级结论。详见 `framework.md`（方法论框架）。

## 运行

### 方式一：浏览器单机版（推荐，零环境、双击即用）

`web/命理交叉验证系统.html` 是**单文件、纯前端**版本 —— 历法库、四套引擎、图表与录入界面
全部内联，无需联网、无需安装、无需服务器。直接**双击**用浏览器打开，填写出生信息即可生成完整报告：

- 四柱八字（四柱表 / 日主强弱 / 大运 / **五行·十神雷达图**）
- 紫微斗数（十二宫**圆形星盘** / 命宫主星 / 三方四正 / 生年四化）
- 周易梅花易数（本卦·变卦·动爻）
- 铁板神数（考时条文）
- 流年逐岁详批（当前年前后共 11 年：**流年四化盘** + **运势评分折线图** + 明细表 + **逐岁年度指导（直白避坑型）**：分事业/财运/人际/健康/时机五维，每句给具体「别做什么、该把劲往哪使」，如「不裸辞/不担保/不替人背债/合同留书面」）
- 四维交叉验证矩阵 + 综合分级结论 + 考时/复核提示
- **人生指导总览**：综合四体系交叉验证，给出「可重点发力领域 / 需设防别踩坑方面」+ 分维度直白建议（含具体红线）+ 大运阶段策略（喜运主动出击放大成果、忌运收着点降风险敞口）
- 一键**导出多年运势 CSV**（用 Excel 打开做逐年追踪，含分维指导列）

> 该版本与 Python 引擎（见 `framework.md`）在四个测试用例上**逐字段对齐**（四柱、紫微、交叉验证分级均一致）。
> 所有运算在本地浏览器完成，**数据不上传**。

### 方式二：Flask 服务端原型（需 Python 环境）

```bash
# 1. 安装依赖（建议在虚拟环境中）
pip install -r requirements.txt

# 2. 启动
python app.py

# 3. 浏览器打开
http://127.0.0.1:5000
```

输入阳历出生日期、时辰、性别与出生地，即可生成完整分析报告：四柱八字 → 紫微斗数星盘
（含十二宫圆形可视化）→ 周易本卦/变卦 → 铁板考时条文 → 流年逐岁详批（含**流年四化盘**与**十年运势走势折线图**）
→ 交叉验证矩阵 → 综合分级结论。报告页支持 **一键导出 PDF / 导出结构化 JSON**（供二次分析）。

## 目录结构

```
MingLi_System/
├── framework.md          # 方法论框架文档（系统定位/交叉验证/分级标准/局限）
├── app.py                # Flask 交互原型
├── requirements.txt
├── engine/
│   ├── constants.py      # 天干地支/五行/纳音/十神/紫微/周易 常量表
│   ├── bazi.py           # 四柱八字引擎（cnlunar + 十神/强弱/大运）
│   ├── ziwei.py          # 紫微斗数引擎（命宫/五行局/十四主星/十四辅星/四化）
│   ├── yijing.py         # 周易梅花易数起卦
│   ├── tieban.py         # 铁板神数考时条文（简化示范）
│   ├── liunian.py        # 流年逐岁详批引擎（推运层）
│   ├── chart.py          # 紫微十二宫圆形星盘 SVG + 十年运势走势折线图 SVG 生成
│   ├── geo.py            # 真太阳时/经纬度修正
│   └── cross_validation.py  # 交叉验证与分级结论引擎
└── templates/
    ├── index.html        # 输入表单
    └── report.html       # 分析报告页
└── web/
    ├── 命理交叉验证系统.html  # ★ 单文件浏览器版（双击即用，推荐）
    ├── lunar.js             # 历法底层（lunar-javascript，仅浏览器版依赖）
    └── engines.js           # 四套引擎 + 图表 + 交叉验证（浏览器版源码）
```

> `web/命理交叉验证系统.html` 由 `web/lunar.js` + `web/engines.js` 静态内联生成；
> `web/engines.js` 与 `engine/*.py` 流派约定一致，可独立在 Node 中 `require` 调用 `ML.analyze()`。

## 说明与边界

- 本系统定位为 **传统文化研究 / 自我认知参考**，非医疗、投资或人生决策建议。
- 八字月柱按节气分界；紫微采用传统安星诀（中州派简化），流派差异已在 `framework.md` 标注。
- 铁板神数为「干支化数 + 示范条文库」，重在考时方法学，非完整秘传条文本。
